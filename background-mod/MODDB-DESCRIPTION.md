Title: Full Throttle Background Remaster - Windows Beta 0.1.0

An unofficial visual mod for Full Throttle Remastered, improving background
detail and selected scenery sprites while preserving scene layouts. Includes
work on animated clouds, signs, doors and other interaction states, plus live
switching between official remastered graphics (F6) and custom graphics (F7).

This release includes an offline Windows installer and a bundled helper.
Extract the ZIP, run Setup.exe, select the folder containing Throttle.exe and
full.data, then use the new "Play Full Throttle Background Remaster.cmd".
No Python installation is needed. Keep the helper running while playing.

Requires a separately installed Windows copy of Full Throttle Remastered.
The installer checks texture compatibility and does not modify the game
executable, archive or saves. Development used GOG build Throttle-1.1.891868;
other editions are not gameplay-verified. Windows 64-bit only.

Beta release: some scene and animation states still need gameplay testing.
This is a background/scenery mod, not a replacement for every character or
cutscene. Artwork was created with AI-assisted redraws and reviewed/integrated
into the game's existing scene geometry.

Installation, removal and troubleshooting instructions are included in README.
Please report visual issues with a screenshot, location/state and game build.
